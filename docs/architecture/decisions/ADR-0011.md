# ADR-0011: One TypeScript/React SPA for desktop, web and mobile, prebuilt into the wheel

**Status:** DECIDED · **Date:** 2026-09-23

## Decision

A single SPA (`clients/app/`, TypeScript + React + Vite) renders every graphical surface. Desktop hosts it in the existing Qt shell (with Edge/browser fallback), web serves it from Core, mobile installs it as a PWA. It is built in CI/release and shipped as static files; runtime needs no Node.

## Why

Three graphical form factors with one behaviour model; the website already uses React/TypeScript; typed API clients generated from the route table prevent drift.

## Alternatives

Keep vanilla JS modules with no build; separate native apps; Electron.

## Tradeoffs

Adds a build toolchain to CI and contributors; the legacy vanilla SPA and the new one coexist until retirement.

## Consequences

Packaging test ensures only built static files ship. CSP forbids inline script.
