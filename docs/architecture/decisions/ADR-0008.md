# ADR-0008: Execution nodes: local in-process in V1, remote contract specified

**Status:** DECIDED · **Date:** 2026-09-23

## Decision

V1 runs one local execution node inside the Core process behind the node contract. Remote nodes (outbound SSE commands + POST reports, heartbeats, GRACE, node tokens, node-bound accounts) are specified but deferred.

## Why

No acceptance scenario needs a second machine; the phone talks to Core on the PC. Specifying the contract now keeps V1 code from assuming locality.

## Alternatives

Separate local daemon process from day one (Vicoa); remote nodes in V1.

## Tradeoffs

Core restart must not kill work: harness processes are detached and adopted on boot.

## Consequences

Process registry on disk; reconciliation by pid + create time.
