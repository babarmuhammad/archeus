# ADR-0025: Graph edge semantics, legend, impact view and the constellation treatment

**Status:** DECIDED (user directive and approval, 2026-09-30) · **Date:** 2026-09-30 · Implementation owner:
P19.5 · Extends ADR-0016 · Rulebook §12, §25

## Decision

1. **Edge treatment by recorded confidence tier** (after Graphify R3). `Relation.confidence_tier`
   records how a stored relation was produced:
   - `EXTRACTED` (deterministic code, and every column edge) → **solid**, 1–3 px by bundle, word
     "recorded";
   - `INFERRED` (a relation a model call described) → **dashed** `[6,4]` at `alpha-recede`, word
     "suggested by Archeus";
   - `AMBIGUOUS` → **dotted** `[1.5,3]`, word "unclear". Core never writes it today, so the style
     is implemented and tested but the **legend does not show it until a loaded edge carries it**.
   The client never infers a tier or a relation (P18 rule kept).
2. **Legend**, generated from `encoding.ts`: shapes, tiers, halo, marker. Collapsible; each row
   is a real checkbox that hides that kind or tier; accessible (a list, not an image).
3. **"What does this affect?"** — an impact view on a focused node: the objects reachable from it
   over *recorded* relations in the loaded neighbourhood, bounded by hops (default 2, max 3), drawn
   as the path highlight and listed in the mirror. No inferred causality; the view states that it
   covers recorded relations in the loaded neighbourhood only.
4. **Constellation treatment:** project hull as a filled volume (`hull` token, one path under the
   strokes); depth by hop distance from focus (three opacity tiers); unfocused edges recede, live
   and selected edges are bright; a live node carries a light core dot inside its shape; a
   **static** 12-junction cage glyph for a project cluster at world level (≥ 48 px), a circle
   below — never rotated; node size encodes open work, clamped.
5. **Bounded by default** (after Cognee R4): depth 1/2, node cap with "+N more" (as built);
   layout computed once, deterministic, never re-run by itself.

## Why

The references ask for clusters, fine lines, depth, transparency and meaningful relationships
(PROMPT 1422-1437; SP 925-927; PPTX slide 11; constellation-gap "the hull is a translucent solid");
Graphify shows the confidence distinction as the primary edge encoding; Cognee shows bounded,
deterministic views.

## Alternatives

Colour per tier (rejected: colour means state); per-cluster hues (rejected in the app, ADR-0017);
community detection in the client (rejected: the graph infers nothing).

## Consequences

Encoding-table tests extended; framebuffer probes for hull, halo and focus; legend and impact e2e.
