# ADR-0021: Provider-terms gate before the first real headless model call

**Status:** OPEN · **Date:** 2026-09-23

## Decision

The user confirms whether automated headless use of subscription accounts, and rotation across several subscriptions, is permitted by each provider's terms **immediately before the first real headless model call** (the first tool-less structured call in P4, P6 or P7, whichever comes first). It is not a P0 gate: P0.5–P3.5 make no real model call. Fake and scripted harnesses/brains are unrestricted for architecture and acceptance testing. Tool-less structured calls are allowed only through the controlled `llmcall` runner once this gate is passed. Real tool-using agent execution additionally stays hard-gated until the P9 policy engine exists. Nothing assumes subscription automation is permitted. (Moved from P0 on 2026-09-23 with the user's explicit approval.)

## Why

The migration kit's feasibility doctrine: a fully sketched plan may still end in "don't". The router and multi-account features depend on this answer.

## Alternatives

Assume permitted; restrict V1 to API keys.

## Tradeoffs

Uncertainty until answered.

## Consequences

If not permitted: the architecture stays intact; real headless calls and executions use supported API-key/provider accounts, and subscription accounts remain available for the user's own interactive and manual sessions.
