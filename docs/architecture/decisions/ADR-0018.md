# ADR-0018: Internal architecture and design documents live under docs/ but are excluded from the manual

**Status:** DECIDED · **Date:** 2026-09-23

## Decision

`docs/architecture/`, `docs/design/` and `docs/research/` hold internal engineering documents. `mkdocs.yml` excludes them (`exclude_docs`), and `tests/test_docs_site.py` reads that block so the nav gate does not require them.

## Why

The requested paths are under `docs_dir`, where any markdown file is a public page; excluding them keeps them internal without moving them.

## Alternatives

Move to `notes/`; publish them in the manual.

## Tradeoffs

Readers must know the docs are internal (stated in each document header).

## Consequences

The exclusion is mutation-verified (removing it fails the nav test). The source reference documents stay gitignored.
