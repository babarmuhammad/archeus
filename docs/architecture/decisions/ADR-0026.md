# ADR-0026: The thread and thread tints

**Status:** DECIDED (user directive and approval, 2026-09-30) · **Date:** 2026-09-30 · Implementation owner:
P19.5 · Amends ADR-0017's palette sentence · Rulebook §7 (thread forms), §23

## Decision

1. **The thread is the signature element**: the visible link from an Archeus action or message
   to the world object it affected. One semantic model, several forms:
   - **T1 conversation → object**: drawn from `Message.links` (Core's record of "the world objects
     it touched") to the object's row when it is on screen; ≤ 600 ms draw-on, once; an off-screen
     target puts the rule on the link instead.
   - **T2 list rule**: a static 2 px rule on the **left edge** of a row whose object changed since
     the user last looked (digest cursor); removed by acknowledgement. **The left edge of a row
     belongs to the thread** — no state or status may use a left rail.
   - **T3 spatial trace**: the travelling marker (ADR-0024) along a live edge, in thread ink.
   - **Inspector**: the object's header shows "changed by Archeus · N ago" with the link back to
     the message or execution when recorded.
   Direction is always action → object. Static when nothing travels.
2. **Thread ink** is near-white on dark (`#F4F1EA`), near-black on light (`#11151C`).
3. **Thread tints**: the user may choose one tint from a curated list derived from the legacy
   palettes' accents. A tint must pass 3:1 on `surface-1`, be ≥ ΔE 30 (CIE76) from every state
   colour and from focus, and **never carries meaning**. Tints are the *only* survival route of the
   39 legacy palettes: they are not skins, themes, appearance modes or cluster colours. The legacy
   migration (P22) maps each legacy theme to its nearest valid tint.

## Why

DS §2 has always named the thread as the one signature element; PROMPT 1338 asks that "the UI
make it clear that the assistant is operating on the user's world"; Core already records the
touched objects (`conversation.py:109-118`) and the SPA ignores them. ADR-0017 said palettes
survive "as accent choices" while DS (after review B.1) says there is no hue accent — this ADR
resolves that contradiction.

## Consequences

ADR-0017's "legacy palettes survive as accent choices" is superseded by clause 3. Contrast/ΔE gate
extended to tints and focus. Client-only: no Core change.
