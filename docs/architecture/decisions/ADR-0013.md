# ADR-0013: Graph relationships in relational tables, not a graph database

**Status:** DECIDED · **Date:** 2026-09-23

## Decision

World and knowledge relationships are rows in `relations`, traversed with recursive CTEs (1-2 hops). Code structure comes from the deterministic import graph. Edge confidence tiers follow Graphify.

## Why

V1 needs small neighbourhoods for one user; a graph DB would be a second store breaking the single-writer/outbox guarantees.

## Alternatives

Neo4j/Kùzu/Ladybug; in-memory NetworkX JSON (Graphify).

## Tradeoffs

Complex graph analytics are out of scope.

## Consequences

Revisit above ~10^6 edges or when multi-hop analytics are required.
