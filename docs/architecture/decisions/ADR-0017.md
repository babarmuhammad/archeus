# ADR-0017: Design language: fixed state colours, one signature element, skins/worlds not carried

**Status:** DECIDED · **Date:** 2026-09-23

## Decision

State colours and glyphs are fixed across all themes; accent is used for primary actions and the thread only; themes are Dark, Light, High Contrast; legacy palettes survive as accent choices; skins and worlds are not carried into the V1 client.

## Why

One colour must mean one thing for an agentic system the user must trust at a glance; 39 palettes × 8 skins cannot hold that.

## Alternatives

Carry skins/worlds; per-theme state colours.

## Tradeoffs

Loses a loved customisation surface (open question: a Classic appearance).

## Consequences

Tokens generated from one table; contrast gate over themes.
