# ADR-0040: A consumed architecture artifact binds implementation; changing it is a plan-level act

**Status:** PROPOSED (the user's directive of 2026-09-30, second orchestration pass, §9; awaiting approval) · **Date:** 2026-09-30 · Implementation: V1.x-O3 · Extends ADR-0034 · Plan: [ARCHEUS_V1_ORCHESTRATION_PLAN.md](../ARCHEUS_V1_ORCHESTRATION_PLAN.md) C5

## Decision

1. **The consumed architecture is fixed.** A task naming an `architecture` artifact in `inputs[]`
   names it at a revision (ADR-0034 §2), and its contract carries `conforms_to`.
2. **Deviation is declared.** The implementer reports any departure as a `DEVIATION:` line, recorded
   on the checkpoint like `DECISION:` lines and surfaced to the reviewer.
3. **The review compares four things:** the user's verbatim request, the architecture artifact, the
   diff and the verification evidence; the verdict states conformance, and an undeclared deviation
   is `changes_requested`.
4. **Only a replan changes the architecture.** A new architecture revision is produced by an
   architecture task in a new PlanVersion, which passes P9 plan approval under the autonomy
   profile. No implementation task can write a new revision of an artifact it consumes.
5. **Architecture-first is the planner's proposal** (by blast radius), validated by Core; the user
   may require it per project as a mission preference. It is never an unrecorded model choice.

## Why

The workflow the user runs by hand — architecture in one model, implementation in another, review
against both — only works if the implementer cannot quietly redefine what was agreed. ADR-0034
already hands the architecture over as a verified artifact; this ADR makes it a contract the
implementation is held to, with the reviewer as the check and the plan approval as the only door
for change.

## Alternatives

Letting the implementer amend the architecture when it declares the deviation and the reviewer
accepts it (a lighter option, left to the user as decision D-10); no binding (rejected: silent
redefinition).

## Tradeoffs

A legitimate architectural discovery during implementation costs a replan.

## Consequences

Extends ADR-0034 (§2 input revision, §4 review package); amends domain-model §7.3 (`conforms_to`)
and the checkpoint (`deviations[]`). No new state machine.
