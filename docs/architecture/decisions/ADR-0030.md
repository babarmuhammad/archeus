# ADR-0030: Phase amendments for the visual architecture — P19.5, the P18 A8 amendment, V1.x-3D and Core owners

**Status:** DECIDED (approved by the user, 2026-09-30) · **Date:** 2026-09-30 · Rulebook §26, §30, §36

## Decision

1. **New phase P19.5 — Visual language and operational presence**, after P19 (which unifies the
   clients and moves Relations/TUI onto `/v1/world/graph`) and before P20 (which then hardens the
   new Core verbs). It owns ADR-0024…0029: tokens, primitives, graph semantics, thread, halo,
   pulse, marker, mark/orbit/favicon, operations strip, live map, Now/Work/inspector/Knowledge/
   Ideas/Resources surfaces, the command palette upgrade, the state matrix, the visual gates and
   the independent design review at its exit. It also owns a **small Core slice**, built before
   the UI that uses it: a Pause-all command and a readable emergency-stop state (P11 rules), and a
   mission priority command read by routing/scheduling (P10 rules) — each an ADR-0006 verb through
   P9 policy. Alternative: fold all of this into P19.
2. **Amendment to P18 A8 (recorded, not silent):** A8's energy rule "one 240 ms opacity step"
   becomes: keep the opacity pulse; add the static activity halo on live objects and the
   event-driven travelling marker (ADR-0024 caps). P18's rejections stand unchanged — they rejected
   mechanisms (perpetual loop, `Math.random`, `sin(T)` breathing, bokeh, ambient stage, never-parking
   loop, tween into layout), not the concepts. The amendment is **implemented in P19.5**, not by
   reopening P18.
3. **P18 closure** needs only: its three manual checks recorded (60 fps on integrated graphics,
   Windows Terminal and conhost, a physical touch device), the doc-only deviation rows (A8
   narrowing; unported legacy renderer items and their dispositions), and optionally the two colour
   defects of ADR-0028 (otherwise they move to P19.5).
4. **Core dependency owners:** event cause for non-automation commands and an execution →
   produced-object record → **P21** (with the trace/replay view, content time ≠ presentation time);
   notifications and push → **P20**; schedule triggers and `next_run` (ADR-0020 decided them; P14
   D14 deferred them with no owner) → **P21**; knowledge "when used" → verify, then P19.5 Core slice
   or P21; a unified decision log → **P21** (optional; the client approximates it meanwhile).
5. **V1.x-3D** (post-V1): the 3D lineage of the flat graph scene, inner-web counter-rotation,
   system nodes. **V1.x**: swipe = decide later, compact density.
6. People/organisation nodes and palette → tint migration stay **P22**; PWA and physical touch
   acceptance **P23**; the website's expression of the same DNA **P25**.

## Why

Every retained concept needs an owner (rulebook §26); no current phase owns visual work after
P18; P14 D14's deferral had no owner; R5: "Do not proceed on inferred approval."

## Consequences

On approval: PLAN gains the P19.5 block and dependency edge; p18-design-gate records the A8
amendment; testing-strategy §7 activates.
