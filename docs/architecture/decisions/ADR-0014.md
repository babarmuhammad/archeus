# ADR-0014: Information architecture: Now, Work, World, Control + Attention + command bar

**Status:** DECIDED · **Date:** 2026-09-23

## Decision

Four destinations (Now = presence + conversation; Work = missions, ideas, runs, manual sessions; World = projects, repos, people, meetings, decisions, knowledge; Control = autonomy, automations, resources, devices, notifications, appearance) plus a global Attention layer and a command bar.

## Why

Maps one-to-one to the user's mental model; merges the spec's Conversation + Current World (both are "arriving"); keeps infrastructure disclosed under Control; fits a four-tab mobile bar and a one-level sidebar.

## Alternatives

Spec's seven surfaces; pptx's six; chat-only; dashboard + chat.

## Tradeoffs

Harness configuration pages move two levels deep (Control → Resources → Claude Code).

## Consequences

One navigation table drives desktop, mobile and TUI.
