# ADR-0003: Stdlib-only runtime for Core

**Status:** DECIDED · **Date:** 2026-09-23

## Decision

Core uses only the Python standard library at runtime (sqlite3, http.server, threading, subprocess, json, hashlib, secrets, hmac, ctypes). Optional extras: `gui` (PyQt6 shell), later `push` (Web Push). The SPA is built at release time and shipped as static files; Node is never needed at runtime.

## Why

Zero runtime dependencies is a stated product property today and a large part of why installation is reliable on Windows. Everything V1 needs server-side is achievable with the stdlib.

## Alternatives

FastAPI/uvicorn + websockets + SQLAlchemy + pydantic.

## Tradeoffs

More hand-written infrastructure (SSE server, pools, validation). No WebSocket (SSE + POST covers every flow). No ECDSA, so Web Push is deferred.

## Consequences

The HTTP server needs explicit request/stream pools. Validation is done in command handlers against dataclasses.
