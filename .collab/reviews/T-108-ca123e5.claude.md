Root cause confirmed by reading `archeus/harnesses/base.py` before and after: the old code
caught the `os.remove(halted_path)` `PermissionError`, re-raised a **new** `OSError(...) from
err`, which then hit the *outer* `except OSError as err: _refuse(..., SpawnWriteFailed)` with
`err` now bound to the wrapper, not the original `PermissionError` — so
`SpawnWriteFailed.__cause__` was the wrapper. `ca123e5` calls `_refuse(paths, msg, err,

`PermissionError` itself, matching the S2-L test. Both old and new code still raise
`SpawnWriteFailed` (same class) at the manager boundary, so `manager.py`'s
