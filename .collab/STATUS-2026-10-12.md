## 3. Findings that change how we work

- **F1 — there is no ACL writer in the product, and no applied-ACE ledger.** `WindowsBoundary` has no grant and no revoke; `IsolationRecord.applied` is empty by design and the ledger records `planned` only. Consequence for S2-G acceptance: "revocation removes every ACE Core applied" cannot be proven against a record that does not exist. The S2-G card should require the apply path to write `applied` and prove revoke by **reading the DACL back**, not by diffing an expected set.
- **F3 — "Core creates every class directory" is a sequence, not a boundary.** Core creates `exec/<id>`, `req`, `res`, `ctl` at spawn (base.py:299-302), but the hook, running inside the isolated process, `os.makedirs` its own mailbox when absent (hook.py:76-80, called at 85/113/143). Harmless while no grant exists (F1); the moment `req/` is granted `rw`, the create rights on `exec/<id>/` become load-bearing, and `check_invariant` never asks who can create.
- **F4 — the shared project workspace is designed, not leaked.** Non-worktree tasks run in the project root itself (manager.py:324-345); the scheduler, not the ACL, is what keeps two tasks apart (engine.py:79-88). Bearing on R7's wording; not a decision.
- **Two sessions, one branch.** The `default`-account session committed `f6abc4d` at 12:42:42 while this session's full suite was running, updated T-006 on the board itself, normalized the blocked statuses, and landed T-012 (`3489a39`, the project-doc records for T-001…T-007 on `pv20-s2`). Nothing was lost — T-006's work was real and this session verified it independently — but two agents committing one branch against one board is how a card gets done twice. `README.md` now carries a rule for it.
- **T-006's green suite is not the argument.** Two of its four fixes relax a test rather than change product code (the J3 expected-module list gains `archeus.cli._api`; the SPA tests wait out the announcer's 5 s latest-wins window and settle before idle checks). Review should judge each relaxation on its stated reasoning.
